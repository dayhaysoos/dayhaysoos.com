This was a result of a library I made, [use-shopping-cart](%22https://useshoppingcart.com%22). I had never planned for any of this, and even before the sponsorship, I got so much value out of pursuing it.

In this post, I'll be going over when it might be a good idea to make a library and what value it can bring to you.

## You might want to create a library if you:

#### Are planning on doing something repeatedly

The first version of use-shopping-cart wasn't even a library. It was code that allowed me to create an e-commerce experience. I didn't think of it being a library at this point, however, I had this feeling I'd want to do this more than once. I hated the idea of writing this code again, so I sought ways to make it easy to re-use. I was using frameworks to do it for me, but the real answer was to make a library out of the important parts of that code. You might have already built something that could be abstracted out into a small library that would save you lots of time if you needed something like that in the future.
